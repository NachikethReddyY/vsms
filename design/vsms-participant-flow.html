From sign-in to a recorded outcome

Every request requires a signed-in staff member. Each material change creates an audit record; participants never create accounts.

If a result crosses a configured threshold, the system says “Flagged for reviewer assessment.” The screener acknowledges the flag and transfers the participant onward.

OFFLINE BRANCH

Offline is a save state, not a failure

The same forms remain usable. Actions are stored locally, retried safely and accepted once through idempotency keys.
