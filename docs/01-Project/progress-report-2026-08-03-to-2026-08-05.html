PR #72 · Authentication and logout hardening

Rogue AI hardened authenticated device enrollment and made local and Cognito global logout behavior truthful.

  • Files changed: auth controller/routes, shared audit utility, OpenAPI, auth-device and logout tests, and generated frontend API client.
