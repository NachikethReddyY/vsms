# VSMS accessibility

Target WCAG 2.2 AA in light and dark themes.

- Keyboard: skip link, semantic landmarks, logical tab order, visible focus, dialog focus trap and restoration.
- Touch: 44px minimum targets; tablet landscape is the primary operating size.
- Status: colour is always paired with an icon and readable label; dynamic saves, failures and queue transfers are announced.
- Forms: labels, instructions, inline errors and a linked error summary; preserve entered data.
- Layout: 200% zoom must retain the current participant, status and primary action; inspector becomes a drawer instead of forcing document-width overflow.
- Motion: honour reduced motion; no content begins hidden behind an animation.
- Theme: meet contrast targets for text, status, focus, disabled and overlay states in both schemes.
