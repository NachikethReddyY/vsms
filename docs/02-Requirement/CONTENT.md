# VSMS content

Write for event staff under time pressure. Name the next action first and avoid diagnosis.

- “Flagged for reviewer assessment” — automated screening threshold met.
- “Referral recommendation generated by screening rules” — reviewer decision still required.
- “Final decision made by reviewer.” — show in reviewer workspaces.
- “Saved safely on this device. Records will synchronise when the connection returns.” — offline success, not failure.
- “Sync needs attention” — use only where a record has a recoverable reason and a visible next action.

Use sentence case, specific verbs, participant-first language and concise labels: “Start screening”, “Open review”, “Retry sync”. Do not use “patient” unless the deployed clinical setting requires it.
